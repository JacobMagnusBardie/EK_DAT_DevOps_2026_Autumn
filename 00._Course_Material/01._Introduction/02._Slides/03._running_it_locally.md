# Getting the database 

```bash
$ scp monkgroup@<ip_address>:/tmp/whoknows.db .
```

Move the database into the `src` folder.

---

# Change the database path

The `/tmp` folder (outside of the source code) is a good place to keep the database. 

But we will change it, since Windows does not support it.

Let's change the variable in `app.py` that defines the path to:

```python
DATABASE_PATH = '../whoknows.db'
```

This points to the `src` folder which is one level above `backend`.

Be careful. The database is now in the repository. Do not push it. It contains users and passwords.

# Make

A build automation tool. Allows us to run commands. 

[Make (software)](https://en.wikipedia.org/wiki/Make_%28software%29)

Actions are defined in a `Makefile`.

*Can you find it?*

---

# Install `make`

Comes with *nix. The following is only needed for Windows users: 

```powershell
$ scoop install make
```

---

# Run using `make`

Execute the command where the `Makefile` is located. 

```bash
$ make init # Creates a new database based on schema.sql
$ make run  # Run the application
```

**Note**: The commands in Make use `python2`. Upgrade this after you've converted from Python 2 to 3.

---

# Run the project with Python 3

While the server is built with Python 2, try to run it with Python 3:

```bash
$ python<???> <server_file>
```

The syntax `<>` means that this is a dynamic of the command.

Type `pyt` and hit **TAB**. It will show the correct choices. For instance, you might need to add `.exe` if you are on Windows.

I have aliased python -> python3.x.x. 

In the slides when I write python the assumption is that it will be Python 3. 

You can either alias is or write `python3`.
